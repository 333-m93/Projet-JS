Ce jeu est inspiré du style de Mario. Le joueur contrôle un prisonnier qui doit s’échapper tout en évitant un policier qui le poursuit.
Le but est de franchir les obstacles, sauter sur les plateformes et atteindre la sortie sans se faire attraper.

Objectif du jeu
Contrôler le prisonnier
Éviter le policier
Passer les obstacles
Atteindre la fin du niveau pour gagner
Commandes
Flèche gauche : aller à gauche
Flèche droite : aller à droite
Espace / Flèche haut : sauter
Fonctionnalités
Déplacements fluides
Sauts sur plateformes
Niveau inspiré des jeux rétro
Système victoire / défaite
